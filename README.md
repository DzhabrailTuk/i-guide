# I-Guide — сайт

Сайт digital-агентства I-Guide: SEO и GEO-продвижение, создание сайтов, Яндекс Директ, SERM и аудит. 115 страниц: 52 услуги, 35 статей базы знаний, 6 городов, страницы групп услуг, дорожная карта.

## Как запустить

Нужен [Node.js](https://nodejs.org) (версия 18 или новее). Сторонние пакеты не нужны.

```bash
npm start
```

Команда собирает сайт и запускает его на http://localhost:4321.

Только собрать сайт (готовые страницы появятся в папке `dist/`):

```bash
node build.js
```

Проверить SEO (один H1 на странице, уникальные title и description):

```bash
node seo-check.js
```

## Где что лежит

| Путь | Что это |
|---|---|
| `src/config.js` | Настройки: домен, город, Telegram, WhatsApp, реквизиты |
| `src/groups.js` | Группы услуг (SEO, GEO, Реклама, Продажи, Сайты, SERM, Аудит) |
| `src/pages/home.js` | Главная страница |
| `src/pages/uslugi/` | Страницы услуг (в подпапках — подуслуги по группам) |
| `src/pages/kb/` | Статьи базы знаний |
| `src/pages/goroda/` | Страницы городов (общий шаблон — `src/lib/city.js`) |
| `src/pages/misc/` | Контакты, цены, подписка, дорожная карта, карта сайта и др. |
| `assets/` | Стили, шрифты, скрипты, иконка |
| `build.js` | Сборщик: из `src/` делает готовый сайт в `dist/` |
| `wordstat/` | Рабочая аналитика (Вордстат, конкуренты) — хранится только локально, в репозиторий не входит |

## Как вносить изменения

- Тексты страниц меняются в файлах `src/pages/**`. Каждая страница — один файл: `title`, `description`, `h1` и содержимое.
- Новая страница = новый файл в `src/pages/`. Меню, карта сайта, sitemap.xml и база знаний обновятся сами.
- Папку `dist/` руками не править — она пересобирается.
- После правок: `node build.js` и `node seo-check.js` — сборщик сам предупредит о битых ссылках.

## Что ещё не заполнено

На сайте отмечены оранжевыми рамками: цены, примеры работ, реквизиты, номер WhatsApp, домен.
