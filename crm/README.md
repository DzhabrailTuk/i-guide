# I-Guide CRM

Своя система для ведения клиентов. Заявки с форм сайта попадают сюда автоматически, компании можно добавлять и вручную.

## Что умеет

- **Журнал заявок** — каждое обращение отдельной записью: с сайта, звонок, Telegram, встреча, обзвон, рекомендация. Фильтры по периоду, категории и каналу, ручное внесение, выгрузка журнала в Excel.
- **Аналитика** — из каких категорий услуг обращаются, откуда приходят (реклама, прямой заход, сайты), каналы, города, заявки по месяцам, сколько стали клиентами.
- **Документ по клиенту** — карточка со всеми данными, обращениями, согласиями на обработку ПДн (дата, IP, текст) и историей: печать или сохранение в PDF.
- **Резервные копии** базы — при запуске и раз в сутки в `data/backups/`, хранятся 30 последних.
- **Список компаний** со статусами: Новая заявка → Связались → Отправлено предложение → В работе → Клиент / Отказ. Счётчики по статусам, поиск по названию, контакту, телефону, сайту и городу.
- **Карточка компании:** контакты, сайт, город, интересующая услуга, источник (откуда пришёл клиент, включая UTM-метки рекламы), следующий шаг с датой. Просроченные шаги подсвечиваются красным.
- **История:** заявки с сайта, заметки, смена статусов и правки — с датой и временем.
- **Повторные заявки** от той же компании (совпал сайт, телефон, Telegram или e-mail) добавляются в её карточку, а не создают дубль.
- **Выгрузка в CSV** — открывается в Excel.
- **Уведомления в Telegram** о каждой новой заявке — если указать бота в `config.json`.

## Защита

- Вход по паролю. Пароль хранится только в виде хеша, 10 неверных попыток за 15 минут блокируют вход.
- Заявки принимаются только с сайтов из `allowedOrigins`, не чаще 10 за 10 минут с одного адреса; есть скрытое поле-ловушка для ботов.
- Заявка без согласия на обработку персональных данных не принимается.
- `config.json` и база `data/` не попадают в репозиторий.

## Запуск

Нужен Node.js 22.5 или новее — база SQLite встроена в Node, сторонние пакеты не нужны.

```bash
node crm/set-password.js "ваш пароль"
npm run crm
```

Панель: http://localhost:4400. Демо с примерами заявок (отдельная временная база): `node crm/demo.js` → http://localhost:4401, пароль указан в `crm/demo.js`.

Сайт вместе с отправкой заявок в локальную CRM: `npm run dev`.

## Настройки — `crm/config.json`

| Поле | Что это |
|---|---|
| `port`, `host` | Где работает CRM. На сервере за nginx оставьте `127.0.0.1`. |
| `allowedOrigins` | Адреса сайта, с которых принимаются заявки, например `["https://i-guide.ru"]`. |
| `secureCookie` | `true`, когда CRM открывается по HTTPS. |
| `trustProxy` | `true`, если CRM стоит за nginx: тогда IP для записи согласия берётся из заголовка прокси. |
| `telegram.botToken`, `telegram.chatId` | Бот для уведомлений о заявках. |

## Перед запуском на сервере

1. Сервер с базой должен находиться в России — этого требует 152-ФЗ для данных клиентов.
2. В `src/config.js` сайта указать `crmUrl` — адрес `https://<адрес CRM>/api/lead` — и пересобрать сайт.
3. В `crm/config.json` прописать домен сайта в `allowedOrigins` и включить `secureCookie`.
4. Регулярно делать резервную копию папки `crm/data/`.
